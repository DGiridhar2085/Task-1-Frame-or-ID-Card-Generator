# Task-1-Frame-or-ID-Card-Generator
Pure client‑side web app that turns any photo into a branded HH Goa 2026 PFP frame (4 themes, stickers, filters) or Builder ID card (name, handle, stack, QR code, magic title generator). Drag‑and‑drop (JPG/PNG/WebP/HEIC), real‑time canvas preview with pan/zoom, download as PNG/JPG , copy to clipboard, or share to X. Zero sign‑up, zero uploads.
